ARGUST — SVG BRAND KIT
======================

Included files
--------------
argust-logo.svg       Primary horizontal logo for light backgrounds (transparent canvas)
argust-logo-dark.svg  Horizontal logo for dark backgrounds (transparent canvas)
argust-mark.svg       Standalone gradient A mark (transparent canvas)
argust-icon.svg       Light app icon
argust-icon-dark.svg  Dark app icon

Usage notes
-----------
- SVG files are vector-based and can be scaled without raster blur.
- The horizontal logo and standalone mark have transparent backgrounds.
- Use argust-logo.svg on light surfaces and argust-logo-dark.svg on dark surfaces.
- Use icon variants as app/icon artwork; platform-specific icon safe areas may need adjustment.
- Wordmark text is kept as editable SVG text. Rendering may use a nearby sans-serif fallback
  if the preferred system fonts (Inter / SF Pro Display) are unavailable.

This is a brand concept package, not a trademark clearance statement.
